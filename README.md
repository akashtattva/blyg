# blyg

The published tree of my blyg, served at <https://akashtattva.github.io/blyg/>.

These files are generated by `npm run export` from a local
[blygger-studio](https://github.com/blygger/blygger-studio) instance. Do not
hand-edit anything here — the next export overwrites it.

- `blyg.json` — the manifest other blygs read to discover this one
- `feed.xml` — the RSS feed
- `items/` — one document per published item
- `archive/` — the full index
- `style.css`, `index.html` — the public page itself
